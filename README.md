# 스트링 아트 설계도 (못 400개 · 검은 실 한 가닥)

`input/photo.jpg`의 인물을, 실제로 못을 박고 실을 걸면 만들어지는 실 그림으로 계산한다. 이미지·영상 생성 AI는 쓰지 않았다.

| 파일 | 내용 |
|---|---|
| `nail_order.txt` | 못 번호 순서표(설계도). 5,113줄 = 그림 선 5,014 + 테두리 이동 99 |
| `final.png` | 완성 예상도 (2240×2240, 테두리에 10번 단위 못 번호) |
| `process.mp4` | 과정 영상 1080×1080, 20초, 30fps |

## 계산 방법
1. **목표 이미지** (`solve.py: make_target`) — 얼굴 중심 정사각형 자르기, GrabCut(고전 그래프 컷)으로 배경을 균일한 회색으로, CLAHE·언샤프로 대비 강화. 눈·눈썹·입(주변보다 어두운 곳)과 윤곽에 큰 가중치.
2. **실 모델** — 실이 지나간 길이 `L`인 픽셀의 어둡기 = `1 − exp(−s·L)` (겹칠수록 포화).
3. **선 고르기** (`solve2.py`) — 못 쌍 전체(같은 변 제외 약 6만 개)에서 가중 제곱오차를 가장 많이 줄이는 선을 탐욕적으로 추가 → 나쁜 선 제거·재추가 → 선 하나씩 같은 못을 공유하는 더 좋은 선으로 교체.
4. **한 가닥으로 잇기** (`euler.py`) — 선이 홀수 개 걸린 못끼리 테두리를 따라 짧게 이어 준 뒤 오일러 경로(Hierholzer)로 모든 선을 "앞 줄이 끝난 못에서 시작"하도록 정렬.
5. **렌더** (`render.py`) — `nail_order.txt`만 읽어서 `final.png`, `process.mp4`를 그린다(설계도와 그림이 일치함을 보장).

다시 만들기: `pip install numpy numba opencv-python-headless pillow` 후 `./run.sh` (ffmpeg 필요, 약 5분).
